# MMORPG Project

A MMORPG built with Unity and Mirror.

## Features
- Real-time action combat
- PvP dungeons
- Loot-based progression
- Multiplayer gameplay

## Tech Stack
- **Engine:** Unity
- **Networking:** Mirror
- **Backend:** C# / MySQL
- **Database:** PostgreSQL

## Getting Started
1. Clone the repo
2. Open in Unity 2022 LTS or newer
3. Run the game
